# Original, quotation and independent evidence

Build two empty stores. In one, ingest digest, repeat, then trial. In the other, ingest trial, digest, then repeat. Compare the final evidence holders, active items and provenance. Ingestion dates and first-assigned slugs may differ.

## Pass/fail checks

- Pass if the digest initially holds only second-hand evidence of the original run. Once the original arrives, its evidence document holds the trial in both stores, with a one-way Quotes link and a Not held row in the digest. Fail if origin or event date depends on arrival order.
- Pass if run B remains independent corroboration in both stores and the release-note instruction survives. Fail if equal row counts collapse the two actual runs or the quotation creates a third.
- Pass if consumer answers agree across orders with their evidence limits intact.
